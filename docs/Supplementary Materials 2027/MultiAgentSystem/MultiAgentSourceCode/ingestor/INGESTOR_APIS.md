# Ingestor Server API Documentation

The Ingestor Server is responsible for data acquisition and preprocessing. It handles web crawling of academic portals and processes uploaded documents (Course Outlines/Programs) to feed the knowledge base.

**Base URL:** `http://<host>:<port>`

---

## 1. System Health
### Health Check
* **Endpoint:** `/health`
* **Method:** `GET`
* **Description:** Verifies if the Ingestor service is active.
* **Response (200 OK):** 
    ```json
    {"status": "Server is ready"}
    ```

---

## 2. Web Ingestion (Crawling & Processing)
### 2.1. Start Web Crawl
* **Endpoint:** `/ingest/web/crawl`
* **Method:** `POST`
* **Query Parameters:** `url` (Target URL to crawl)
* **Description:** Triggers the `WebCrawler` to extract major and subject information from a given URL.
* **Response (200 OK):** 
    ```json
    {
      "url": "string",
      "major_filepath": "path/to/csv",
      "subject_filepath": "path/to/csv",
      "major_subject_filepath": "path/to/csv",
      "message": "Crawling completed successfully"
    }
    ```

### 2.2. Summarize Web Content
* **Endpoint:** `/ingest/web/summarize`
* **Method:** `GET`
* **Description:** Processes crawled web data through an LLM to generate concise summaries.

### 2.3. Process Crawled Data to DB
* **Endpoint:** `/ingest/web/process`
* **Method:** `GET`
* **Query Parameters:** `file_types` (Default: "major,subject,major_subject")
* **Description:** Reads the CSV/JSON files generated by the crawler and inserts/updates the data in the main database.

---

## 3. File Ingestion (Documents)
### 3.1. Process Academic Program
* **Endpoint:** `/ingest/file/program`
* **Method:** `POST`
* **Content-Type:** `multipart/form-data`
* **Parameters:** 
    - `file`: (Binary - PDF/DOCX)
    - `major_code`: (Query string)
    - `level_id`: (Query string, e.g., "DH" for Undergraduate, "CH" for Postgrad)
* **Description:** Uploads a program file, extracts curriculum data, and inserts it into MySQL.

### 3.2. Process Subject Outline
* **Endpoint:** `/ingest/file/outline`
* **Method:** `POST`
* **Content-Type:** `multipart/form-data`
* **Parameters:** 
    - `file`: (Binary - PDF/DOCX)
    - `subject_code`: (Query string)
* **Description:** Uploads a course outline, uses LLM to summarize the syllabus/content, and updates the database.
* **Response (200 OK):**
    ```json
    {
      "status": "success",
      "data": { "summarized_content": "..." }
    }
    ```

---

## 4. Technical Workflow
1. **Web Flow:** `Crawl` (Get Raw) -> `Summarize` (Refine) -> `Process` (Save to DB).
2. **File Flow:** `Upload` -> `FileProcessor` (Extract/AI Summary) -> `Save to DB`.

## 5. Error Codes
* `404`: Not Found (Specific file or subject code missing).
* `500`: Internal Server Error (Crawler failure, LLM API timeout, or Database connection error).
